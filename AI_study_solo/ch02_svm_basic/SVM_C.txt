C


SVM에서 C 값의 범위는 데이터셋과 문제의 특성에 따라 달라집니다.
하지만 일반적으로 다음과 같은 범위를 사용하며, 이를 기반으로 실험적으로 최적값을 찾습니다:

1. 일반적인 초기 범위
    작은 C 값 (0.01 ~ 1):
    데이터를 단순하게 처리하거나,
    약간의 오분류를 허용하여 일반화 성능을 높이고 싶을 때 사용합니다.
        예: 노이즈가 많은 데이터셋.

    중간 C 값 (1 ~ 10):
    대부분의 문제에 적합한 기본 설정입니다.
    너무 복잡하지 않으면서도 정확도가 적당히 높은 결정 경계를 생성합니다.
        예: 노이즈가 적고, 대부분의 데이터가 잘 분리되는 데이터셋.

    큰 C 값 (10 ~ 100 이상):
    데이터의 정확한 분류를 우선시하며, 특이 케이스를 민감하게 처리해야 할 때 사용됩니다.
        예: 특이 케이스가 중요한 데이터셋(정확도가 매우 중요한 경우).


2. 실험적으로 C 값 조정
    실제 데이터에서 최적의 C 값을 찾기 위해 로그 스케일을 사용하는 것이 일반적입니다.
        예: [0.01, 0.1, 1, 10, 100]처럼 지수적으로 증가하는 값을 테스트합니다.

    이 방식은 값의 변화를 효율적으로 탐색할 수 있도록 해줍니다.


3. C 값의 선택 기준
    C 값을 낮게 잡아야 하는 경우:
    노이즈가 많고, 과적합 위험을 최소화하고 싶을 때.
    데이터가 복잡하지 않은 경우.

    C 값을 높게 잡아야 하는 경우:
    정확한 분류가 매우 중요할 때.
    데이터가 명확히 구분되고, 노이즈가 거의 없을 때.


4. 교차 검증을 활용한 최적화
    C 값을 정밀하게 선택하려면, 교차 검증을 통해 테스트하는 것이 좋습니다.
    GridSearchCV 같은 도구를 사용해 특정 범위를 설정하고 최적값을 찾는 것이 일반적입니다:

    from sklearn.model_selection import GridSearchCV
    from sklearn import svm

    param_grid = {'C': [0.01, 0.1, 1, 10, 100]}
    svc = svm.SVC(kernel='rbf', gamma=0.1)  # 필요에 따라 커널 조정

    grid = GridSearchCV(svc, param_grid, cv=5)  # 5-fold 교차 검증
    grid.fit(X_train, y_train)

    print("Best C value:", grid.best_params_['C'])


C와 Gamma 동시 조정 테스트
    from sklearn.model_selection import GridSearchCV
    from sklearn.svm import SVC

    # 파라미터 후보 설정
    param_grid = {
        'C': [0.1, 1, 10, 100],
        'gamma': [0.0001, 0.001, 0.01, 0.1]
    }

    # SVM 모델과 GridSearchCV 사용
    grid = GridSearchCV(SVC(), param_grid, cv=5, scoring='accuracy')
    grid.fit(X_train, y_train)

    # 최적의 파라미터 출력
    print("Best Parameters:", grid.best_params_)
