데이터 포인트의 구성
데이터 포인트는 보통 다음과 같이 구성됩니다:

    특징(Feature): 데이터의 특정 속성을 나타내는 값입니다.
        예를 들어, 이미지 데이터에서는 각 픽셀이 특징이 될 수 있습니다.

    레이블(Label): 데이터 포인트가 속하는 카테고리나 결과를 나타냅니다.
        예: 숫자 이미지 데이터를 분류할 때, "숫자 3"이라는 레이블이 있을 수 있습니다.

    예를 들어, 데이터 포인트는 다음과 같은 형태로 나타날 수 있습니다:
    숫자 이미지: [0, 12, 255, 128, ...] 여기서 각 숫자는 픽셀의 밝기를 나타내는 특징이고,
    레이블은 해당 이미지가 "3"이라는 것을 나타냅니다.


데이터 포인트의 역할
    학습(Training): SVM과 같은 모델은 여러 데이터 포인트를 학습하여 패턴을 찾고 결정 경계를 만듭니다.
    테스트(Test): 학습된 모델은 새로운 데이터 포인트를 예측하거나 분류합니다.


데이터 포인트의 예시
    이미지 데이터:
    하나의 이미지가 하나의 데이터 포인트입니다.
        특징: 각 픽셀 값.
        레이블: 이미지에 그려진 숫자(예: 3, 5).

    테이블 데이터: 
    한 줄의 데이터가 하나의 데이터 포인트입니다.
        예: 학생 성적 데이터에서 이름, 과목별 점수, 최종 성적 등.

    시간 시계열 데이터:
    특정 시간의 값이 데이터 포인트입니다.
        예: 온도 데이터에서 특정 시간의 온도 측정값.
