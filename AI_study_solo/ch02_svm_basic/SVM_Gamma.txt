gamma의 의미


gamma는 데이터 포인트의 영향 반경을 결정합니다.
작은 gamma 값은 개별 데이터 포인트가 멀리 떨어진 포인트에도 영향을 미치도록 설정합니다.
반대로, 큰 gamma 값은 개별 포인트의 영향이 아주 가까운 주변에만 집중됩니다.
이는 결정 경계(hyperplane)가 단순한지, 복잡한지에 큰 영향을 미칩니다.


gamma의 작동 방식
    1. 작은 gamma 값
    데이터 포인트 간의 영향력이 멀리까지 퍼집니다.
    결과적으로, 결정 경계가 부드럽고 단순해집니다.
        장점: 모델이 데이터의 전반적인 패턴을 잘 학습합니다(과적합 위험 낮음).
        단점: 데이터의 세부적인 패턴을 잘 반영하지 못할 수 있습니다(언더피팅 가능성).

    2. 큰 gamma 값
    데이터 포인트의 영향이 가까운 범위에 국한됩니다.
    결과적으로, 결정 경계가 매우 복잡해집니다.
        장점: 데이터의 세부적인 패턴까지 정밀하게 반영합니다.
        단점: 모델이 학습 데이터에 지나치게 민감해질 수 있습니다(과적합 위험 높음).


gamma 값의 선택 기준
    작은 gamma:
    데이터의 전체적인 경향성을 학습하고자 할 때 적합합니다.
    노이즈가 많은 데이터나 과적합을 피하고 싶을 때 사용합니다.

    큰 gamma:
    개별 데이터 포인트를 세부적으로 반영하고, 높은 정확도를 요구할 때 적합합니다.
    과적합 위험이 있지만, 정밀한 결정이 필요할 때 사용됩니다.


gamma 값 조정 방법
    최적의 gamma 값을 찾으려면 교차 검증(cross-validation)을 활용하거나 Grid Search를 사용합니다.
    gamma 값은 일반적으로 로그 스케일로 설정하여 탐색합니다:

    예:

    python
    from sklearn.model_selection import GridSearchCV
    from sklearn import svm

    param_grid = {'gamma': [0.001, 0.01, 0.1, 1, 10]}
    svc = svm.SVC(C=1)  # C 값은 고정

    grid = GridSearchCV(svc, param_grid, cv=5)
    grid.fit(X_train, y_train)

    print("Best gamma:", grid.best_params_['gamma'])


gamma 값의 일반적인 범위
    작은 값 (e.g., 0.001, 0.01): 데이터가 복잡하지 않고 전반적인 패턴을 학습하는 경우.

    중간 값 (e.g., 0.1): 대부분의 일반적인 데이터에 적합.

    큰 값 (e.g., 1, 10): 세부 패턴을 정밀히 반영해야 하거나, 데이터가 명확히 분리되는 경우.


C와 Gamma 동시 조정 테스트
    from sklearn.model_selection import GridSearchCV
    from sklearn.svm import SVC

    # 파라미터 후보 설정
    param_grid = {
        'C': [0.1, 1, 10, 100],
        'gamma': [0.0001, 0.001, 0.01, 0.1]
    }

    # SVM 모델과 GridSearchCV 사용
    grid = GridSearchCV(SVC(), param_grid, cv=5, scoring='accuracy')
    grid.fit(X_train, y_train)

    # 최적의 파라미터 출력
    print("Best Parameters:", grid.best_params_)
