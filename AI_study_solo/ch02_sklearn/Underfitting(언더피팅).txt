언더피팅(Underfitting)


언더피팅(Underfitting)은 과적합(Overfitting)과 반대의 개념으로
머신 러닝 모델이 훈련 데이터의 패턴을 제대로 학습하지 못하는 상태를 말합니다.
이로 인해 모델이 훈련 데이터는 물론 테스트 데이터에도 낮은 성능을 보이게 됩니다.


언더피팅의 특징
    훈련 데이터에서 낮은 성능:
    모델이 훈련 데이터에 포함된 중요한 패턴을 제대로 학습하지 못함.

    테스트 데이터에서도 낮은 성능:
    일반화 능력이 낮아 테스트 데이터에서도 기대 이하의 결과를 나타냄.


언더피팅이 발생하는 이유
    모델이 너무 단순한 경우:
    모델의 복잡도가 데이터의 패턴을 표현하기에 부족할 때 발생.
        예: 고차원 데이터를 선형 모델로 학습하려고 할 때.

    특징 부족 또는 잘못된 선택:
    데이터셋이 충분한 특징(Feature)을 포함하지 않거나, 모델에 필요한 중요한 특징이 누락된 경우.

    학습 시간 부족:
    모델을 충분히 학습하지 않으면 데이터의 패턴을 제대로 학습할 시간이 부족합니다.

    하이퍼파라미터 설정 문제:
    SVM의 경우, gamma나 C 값이 적절하지 않아 데이터의 복잡성을 반영하지 못하는 경우가 포함됩니다.

    데이터가 너무 적거나 품질이 낮음:
    잘못된 데이터로 학습을 하면 모델이 제대로 된 패턴을 학습하지 못합니다.


언더피팅이 미치는 영향
    모델이 너무 단순한 결정 경계를 생성하게 되어 복잡한 데이터의 패턴을 학습하지 못합니다.

    데이터에 내재된 주요 관계와 패턴을 놓쳐, 훈련과 테스트 데이터 모두에서 낮은 정확도를 초래합니다.


언더피팅 방지 방법
    모델 복잡도 증가:
    더 복잡한 모델(예: 다항식 차수를 높이거나, 복잡한 신경망 구조)을 사용하여 데이터 패턴을 더 잘 학습하게 합니다.

    더 많은 특징 추가:
    데이터셋에 중요한 정보를 나타내는 새로운 특징을 추가하거나, 특징 선택 과정을 최적화합니다.

    하이퍼파라미터 튜닝:
    모델의 하이퍼파라미터를 조정하여 데이터의 복잡성을 반영하도록 합니다.
    예: SVM에서는 gamma와 C를 증가시켜 경계를 더 세밀하게 설정.

    더 많은 학습 시간 확보:
    모델 학습 과정을 충분히 반복하여 패턴을 학습할 수 있는 기회를 줍니다.

    데이터 확장 및 품질 개선:
    데이터의 양을 늘리거나 품질이 낮은 데이터를 제거하여, 학습에 적합한 데이터를 확보합니다.

    적합한 모델 선택:
    데이터셋에 비해 지나치게 단순한 모델 대신, 데이터의 복잡성을 반영할 수 있는 적절한 모델을 선택하세요.
